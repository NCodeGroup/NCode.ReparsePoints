# C# Conventions

Before editing a `.cs` file, read `.github/instructions/csharp.instructions.md` and follow it. It is the single copy of the C# conventions, shared with GitHub Copilot. In a test project (`<Name>.Tests`), also read `.github/instructions/csharp-tests.instructions.md`. The decisions behind them are in `docs/decisions/project-template/`.
